##基础知识 ###基础知识：电压即两点间电势差 **电压**：两点间电势差：类似如两端电压、压降、压差、$V_{AB}$均为两点电势差 >电压差值产生高度差，电荷被推动，形成了电流 **欧姆定律**：$I= \frac{U}{R}、R= \frac{U}{I}、U= I*R$ ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261008195648381-723100350.png) **电路短路/断路**： - 短路 = 电流抄近路，低阻大电流，危险要断电(无元器件正负极相连(电阻小)电流无限大) - 断路 = 那条路不通 = 该路电流为 0 **串联**：电流相同，电压按电阻正比分；**并联**：电压相同，电流按电阻反比分，总电流等于各支路电流之和 **强弱驱动**：电源与元件间的阻抗，阻抗小则为强驱动，反之 **功率**：$P=I * U$，w瓦特 常用符号： ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261009031121997-811279494.png) ###求法 **基础知识**： - 串联：电流处处相等$I_总 = I_1 = I_2$，总电压等于各元件电压和$U_总 = U_1 + U_2 + ····$，总电阻$R_总 = R_1 + R_2 + ···$ **分压**：$V_{out} = V_{in} * \frac{某一电阻}{总电阻和}$ - 并联：电压处处相等$U_总 = U_1 = U_2$，电流$I = I_1 + I_2$，电阻$\frac{1}{R_总} = \frac{1}{R_1} + \frac{1}{R_2}$ >常用R = $\frac{R_1 R_2}{R_1 + R_2}$ **分流(采用电导)**：$I_某 = I_总 * \frac{G_某}{G_1 + G_2 + ···} = I_总 * \frac{\frac{1}{R_某}}{\frac{1}{R_1} + \frac{1}{R_2} + ···} $ >电导G = $\frac{1}{电阻R} $ ##实用方法 测电压要并联（表笔搭两端），测电流要串联（把表串进回路），测电阻必须断电、单独测 **元件接GND**：元件 + 导线(理想R=0，U=0*R) + 接GND，会有元件电压被GND强行拉到0 ###电容 **(何时可)电容视作导线**：当电容两端的电压不能突变时，在 **"突变发生的瞬间"**，它相当于短路（导线） - 接通直流瞬间(充电)：内部无电荷($V_A=V_B$)，类似导线 - 高频交流电：交流电大小方向不断改变，致使不断充放电，类似导线 **低/高通滤波电路(RC)**：利用电容充放电特性滤除噪声，$f_t = \frac{1}{2\pi RC}$ - 相等时有-3db衰减 为 0.707($\frac{1}{\sqrt{2}}$)倍 ##元件篇 ###电阻：主要起到限流作用(供电电压>负载电压) 直耗电阻的色环识别，与贴片电阻识别 - (色环)前3/4个根据颜色代表大小 * 右边精度 - 贴片： - 整数：最右为$10^x$ - 字母(后为小数)：前为整数，后为小数 ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261001131041788-704030001.png) (电阻识别表) **电阻功率**：$P=I * U$，结合 **(欧姆定律)** 有$ P = I^2 * R、P = \frac{U^2}{R} $ >超过功率会发热甚至超载，所以尽可能：实际 < 负载 串联分压，并联分流 **电阻(并联)分流**：电流按电阻反比分配$\frac{I_1}{I_2} = \frac{R_2}{R_1}$，电阻越大，电流越小 根据$I_{\text{总}} = I_1 + I_2 + \cdots + I_n$，对每条支路用欧姆定律：$I_{\text{总}} = \frac{U}{R_1} + \frac{U}{R_2} + \cdots + \frac{U}{R_n} = U \left( \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n} \right)$ 并联部分也可以看成一个等效电阻 $R_{\text{总}}$：$I_{\text{总}} = \frac{U}{R_{\text{总}}}$，两式相等： $$ \frac{U}{R_{\text{总}}} = U \left( \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n} \right)\Leftrightarrow \frac{1}{R_{\text{总}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n} $$ **电阻(串联)分压**：$\frac{U_1}{U_2} = \frac{R_1}{R_2}$，电阻越大，分压越大 ###电容：类似电池储能，保证$电压_+ > 电压_-$，即不能接反 **(重要)特性：电容两边相对电压不能突变，两边电压可以同时突变** e.g. ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261020092555716-909051334.png) 有s2闭合，电容短路(电容正负极$V_A = V_B = 5$)全打在$R_7$，而后电容充电(慢慢变成电阻)，同$R_7$承担5V电压，$V_B下降$直到电容满电断路(电阻无穷大)，电路无电流 s2断开，s3闭合时，$V_B=5$且为保证电容两端电压不能突变，$V_A$被拉高到10V(耦合) >耦合：地方的电压变化，通过电容“传染”或者“带动”了另一个地方 波形变化. ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261020110515860-51633617.png) (电容选择表) **电容储能** - **电容充电时间常数**：$\tau = R \times C$(固定C变R)，即充电速度与电流(电阻)与电容大小有关 **电容稳压**：当电路中突然需要大电流时，电容在(电源真空期)临时供电，防止电压跌落 - 滤波：稳定电容2端电压(所以电路可能存在多个电容) ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261020130448565-103159605.png) >临时需要大电流时，电压跌落： 1.线路电感(寄生电感)：导线存在电感"抗拒电流突变" 2.电源电阻：内阻在小电流时影响小，电流突然增大时，会产生压降(U = IR，内阻会吃掉电压) **容抗计算**：$R_c = \frac{1}{2\pi fc} $，f频率，c电容 >所以若使用DC频率=0，有 $\frac{1}{0}$，断路 ##应用篇 ###自举电路：利用电容两边相对电压不能突变，两边电压可以同时突变特性 ###(rc)充放电延迟：利用电容充放电延迟做(芯片等)延迟供电 (这里通过充电系数公式计算) 上电延迟： ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261020105841737-118343218.png) $r+元件+c \Leftrightarrow r + c + 元件$ 放电延迟：电容比作电源 ![image](https://img2024.cnblogs.com/blog/3267933/202610/3267933-20261020110325476-207039470.png)
